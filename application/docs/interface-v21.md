# Interface v2.1

Mode : Operate. Refonte libre explicitement déléguée par l’utilisateur. Construction directe des surfaces fonctionnelles ; aucun visuel généré n’est une autorité de mise en page.

## Direction contract

THESIS : un atelier de notes où la page, le micro et l’image gardent chacun une place fixe ; le contenu reste la surface principale.

OWN-WORLD : surfaces claires froides, encre violette réservée à l’action active, Segoe UI, traits discrets, contrôles rectangulaires arrondis de 8 px. Le thème nuit conserve la même structure.

STORY : choisir un dossier, retrouver un fichier, écrire ou dicter, voir la confirmation et retrouver les médias associés.

FIRST VIEWPORT : bibliothèque latérale de 236 px ; note large et lisible au centre ; statut de sauvegarde dans la barre de la note ; dossier persistant au pied de la bibliothèque. Barre vocale indépendante avec destination, mode, action Parler/Arrêter. Éditeur capture avec outils fixes et grande surface de travail.

FORM : outil de bureau organisé autour d’un document. Le lanceur de sélection de direction est indisponible dans cet environnement (moteur absent) ; choix manuel sous délégation de l’utilisateur, sans clé de tirage inventée. Interaction signature : les trois surfaces rangent leur résultat dans le même dossier sans imposer de navigation.

FINISH : unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
